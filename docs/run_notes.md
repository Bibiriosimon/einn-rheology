# Run notes and provenance

## Model roles

- Table 1 uses a numerical TransRheo backbone and a template-based residual correction. The archived templates reproduce exactly from the stored prior banks. These banks include the historical training and validation residual procedure. The current `benchmark_llm_transrheo_datafractions.py` calls a newer KREPC training interface. The two checked workflows are recomputing metrics from frozen predictions and evaluating original saved weights. Recovering an executable, exact historical trainer for all Table 1 methods remains open.
- Table 4 uses a separately archived deterministic-summary ablation workflow. The archive supplies the source of the ablation runner and the archived metrics. The old shell runner documents its original settings and uses shared output directories. Use a separate output directory for each variant in any future rerun.
- The deterministic, DeepSeek Flash and DeepSeek Pro KREPC runs have separate identities. The locators record exact archived IDs, ranking and page fields. The frozen pooled arrays recover the original head inputs and permit offline inference without sending prompts to the provider. They stop at the text encoder output and do not independently regenerate retrieval, prompts or provider responses. The archived code implements the generator, but recreating the historical requests takes the original lawful evidence inputs, cache and provider specification.

## Data

The primary archive provides `data/new_MDdata.xlsx` and `data/new_MDdata_406_records.csv`. Variables are filler volume fraction, reduced temperature, log shear rate and log viscosity. The full processed archive has 406 distinct triples and 105 (filler fraction, temperature) groups. The set overlaps an earlier 195-row file at 186 distinct coordinates. `data/legacy_coordinate_audit.csv` records that relationship. Authorship, physical provenance, simulation protocols and permission for redistribution of the additional 220 coordinates require source documentation. The related experimental source is [Li et al., J. Phys. Chem. B 2023](https://doi.org/10.1021/acs.jpcb.3c01697). Shared numeric coordinates alone do not establish the physical lineage of individual runs.

SciBERT was obtained from the [AllenAI upstream model](https://huggingface.co/allenai/scibert_scivocab_uncased). We preserve the archived config, and the separate inference weight deposit provides the archived tokenizer vocabulary. Follow the upstream license and notices for these assets. The authors should establish the license for their own code, data and derived features before external distribution. The review bundle contains bibliography and evidence coordinates and omits publisher textbooks, free-text evidence fields and API response caches. This allows independent checks on the derived artifacts. Permission to use the underlying passages for reproducing retrieval and re-encoding must be addressed separately.
